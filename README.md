# Scooply

AI news, curated by who you are. Scooply reads every platform, every day, and keeps only the AI stories that fit your level and your interests.

**Live site: [scooply-eta.vercel.app](https://scooply-eta.vercel.app)**

Every push to `main` deploys to the live site on Vercel.

## Run it on your own computer

For local development only — this address works on your machine while the dev server is running:

```bash
bun install
bun dev
```

Then open `http://localhost:3000`.

## Project notes

- Built with Next.js (App Router) and Tailwind CSS v4.
- Design tokens and motion live in `src/app/globals.css`; the design system is documented at `/design-system`.
- Illustrations are generated by `bun scripts/illustrations.ts` (engraving style by default).
